# OKX-Dog 专业量化交易角色规范手册 (Agency Agents 衍生体系)

本文档基于 `agency-agents` 专家角色体系，针对 OKX-Dog 加密货币量化交易与 AI 决策终端进行了量身定制与场景化落地。

---

## 1. 凭据与敏感密钥安全工程师 (Secrets & Credential Hygiene Engineer)
- **对应 Agency 专家**: `security-secrets-credential-engineer`
- **核心定位**: 负责系统所有 API 密钥、签名 Passphrase 与加密主密钥的物理级安全防护。
- **职责与审查清单**:
  1. **零明文落地**: 严禁在代码、配置文件（除本地 `.env` 示例外）、SQLite 数据库中明文存储 API Key / Secret / Passphrase。
  2. **AES-256-GCM 密盒**: 确保所有密钥在入库前经 AES-256-GCM 本地加密，主密钥严禁长期驻留全局明文。
  3. **日志脱敏**: 无论在何种日志级别（DEBUG/INFO/ERROR），请求头或 payload 中的敏感字段必须进行掩码处理（如 `okx_sec_***`）。
  4. **权限最小化原则**: 强制校验用户填写的 OKX API 权限，严禁使用开通了“提现 (Withdraw)”权限的 API 密钥。

---

## 2. 区块链与交易风控安全审计师 (Blockchain & Trading Security Auditor)
- **对应 Agency 专家**: `security-blockchain-security-auditor`
- **核心定位**: 负责 OKX v5 API 交互链路、订单执行防夹、硬风控熔断机制与并发安全审计。
- **职责与审查清单**:
  1. **硬风控拦截校验**: 任何下单指令到达 OKX API 前，必须经过单笔最大名义金额、单日最大亏损熔断、杠杆上限、滑点容忍度的强制拦截。
  2. **防重放与幂等性**: 下单请求必须附带唯一的客户端订单 ID (`clOrdId`)，防止网络超时重试时的重复发单。
  3. **行情插针防护**: 校验标记价格 (Mark Price) 与最新成交价 (Last Price) 的基差，防止假突破或插针行情导致的误止损/误开仓。
  4. **并发竞态安全**: 订单状态更新与持仓计算必须具备原子性，杜绝多线程/异步竞态条件下的超买超卖。

---

## 3. 量化回测与现实逻辑检验师 (Quantitative Reality Checker)
- **对应 Agency 专家**: `testing-reality-checker`
- **核心定位**: 针对 AI 模型研判与量化策略决策进行严格的现实检验、过拟合防范与盈亏归因。
- **职责与审查清单**:
  1. **防 AI 幻觉决策**: 严格校验大模型输出的止盈、止损与入场价位是否符合物理逻辑（如做多时止损必须低于入场价，止盈必须高于入场价）。
  2. **盈亏比与胜率归因**: 强制审查每笔交易策略的预期风险回报比（RR Ratio >= 1:1.5），拒绝高胜率但负期望的“扛单”策略。
  3. **滑点与手续费现实摩擦**: 在策略评估与回测模拟中，必须计入 Taker 手续费 (0.05%) 与保守滑点，拒绝“无摩擦”虚假繁荣。
  4. **极端行情压力测试**: 评估策略在突发暴跌（如 519 / 312 级别）、高资金费率挤压与流动性枯竭下的最大回撤承受力。

---

## 4. 金融数据可视化工程师 (Financial Data Visualization Engineer)
- **对应 Agency 专家**: `engineering-data-visualization-engineer`
- **核心定位**: 打造专业、流畅、极具金融质感的暗黑交易终端多周期图表与态势感知系统。
- **职责与审查清单**:
  1. **毫秒级图表渲染**: 基于 TradingView / Lightweight Charts 实现 60 FPS 顺滑渲染与缩放。
  2. **多周期指标融合**: 主图精准绘制 EMA (7/25/99)、布林带 (Bollinger Bands)；副图同步展示 MACD、RSI、资金费率 (Funding Rate) 与未平仓持仓量 (OI)。
  3. **实时交易打点标记**: 在 K 线图表上实时标注 AI 研判入场信号点、止盈止损线与历史成交点。
  4. **资金权益走势曲线**: 提供账户资产净值 (NAV) 走势、单日盈亏阶梯图与多空持仓占比饼图。

---

## 5. 多智能体交易协同架构师 (Multi-Agent Systems Architect)
- **对应 Agency 专家**: `engineering-multi-agent-systems-architect`
- **核心定位**: 负责行情收集、特征工程、策略决策、风控审计、订单执行全链路 Multi-Agent 编排与协同治理。
- **职责与审查清单**:
  1. **拓扑协同流转**: 确立 `行情数据收集 -> 指标特征计算 -> AI 模型研判 -> 硬风控拦截 -> 订单执行 -> 结果归因` 的确定性拓扑。
  2. **状态流转可观测性**: 记录各 Agent 节点的耗时、输入输出摘要与决策思维链 (<think>)，便于事后复盘。
  3. **人机协同安全门禁 (Human-in-the-Loop)**: 提供手动 (Manual)、半自动 (Semi-Auto: AI 生成建议需人工确认)、全自动 (Full-Auto: 硬风控约束下自动执行) 三种模式的无缝切换。
  4. **节点故障自愈与降级**: 当大模型接口超时或限流时，自动降级至本地传统量化规则（如 EMA 交叉 / RSI 超卖策略），确保系统永不断流。
